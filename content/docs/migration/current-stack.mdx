## Official constraints

- Next.js 16.2 requires Node.js 20.9 or newer and uses Turbopack by default. This repository raises the floor to Node.js 22.18 because Oxlint's TypeScript configuration requires native TypeScript execution; CI pins Node.js 24.
- Fumadocs' current generator directly supports Bun and Oxlint and generated this repository structure.
- Fumadocs MDX uses the current macro API (`defineDocs`) in the generated scaffold.
- TypeScript 7.0 is the primary compiler, but its 7.0 release does not expose the legacy programmatic API. The TypeScript team explicitly recommends a side-by-side TS6 compatibility package for tools that still import that API, and calls out MDX ecosystems as a current limitation.
- Oxlint type-aware linting uses `typescript-go`, requires TypeScript 7, and is enabled with `oxlint-tsgolint`.

`@typescript/typescript6` 6.0.2 depends on the latest TypeScript 6 runtime. Bun 1.3.14 currently resolves the package's nested npm alias incorrectly, so a repository patch routes its public API and `tsc6` command to the explicitly pinned `typescript6-runtime` 6.0.3 package. This is a package-manager compatibility patch, not a substitute for TypeScript 7.
