## Roles

- GPT-5.6 Sol Ultra: 移行実装。旧 worktree を読み取り専用比較対象として、段階的に新 scaffold へ実装します。
- Cursor Grok 4.5: 仕様漏れ、旧新の機能差、運用・セキュリティ・コンテンツ移行リスクを重点レビューします。
- Cursor Opus 5: 型安全性、Next.js / React / Fumadocs の設計妥当性、保守性、過剰実装を重点レビューします。

レビュー担当は修正せず、severity、ファイルと行、再現条件、影響、推奨修正を報告します。実装担当は指摘を根拠とともに採用・却下し、再度すべての検証を実行します。

## Review gates

1. scaffold baseline
2. content/frontmatter migration
3. routes and navigation
4. publishing surfaces
5. integrations and caching
6. final parity and release readiness

Cursor Agent CLI は認証後に、repository root の `docs/reviews/cursor-grok-4.5.md` と `docs/reviews/cursor-opus-5.md` をそれぞれ prompt として plan/read-only mode で実行します。

2026-08-02 の再実行では `--trust` と legacy worktree の追加 read-only root を明示しました。最初の Grok 4.5 review は actionable finding なし、Opus 5 review は ImageZoom 回帰、Oxlint coverage、configuration type gate、failure diagnostics などを指摘しました。全指摘の採否を記録して修正し、両モデルで修正差分を再レビューしました。Grok の残件は Wiki の incremental cache 文言 1 件、Opus の残件は Node / typegen gate と説明上の 7 件で、すべて反映後に canonical CI と browser zoom smoke を再実行しました。
